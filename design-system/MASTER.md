# 설계 검토 뷰어 디자인 시스템 (MASTER)

화면 전체에 적용하는 기준이다. 특정 화면만 다르게 해야 하면 `pages/<화면>.md`에 차이만 적고, 그 파일이 이 문서보다 우선한다.
토큰의 실제 값은 [src/styles.css](../src/styles.css)의 `:root`가 기준이고, 이 문서는 쓰는 규칙을 적는다.

## 방향

- **제품**: 고객 요구사항 문서에서 만든 설계 산출물을 담당자가 검토하는 업무 도구. 오래 읽고, 비교하고, ID로 오간다.
- **스타일**: Minimalism & Swiss Style — 격자, 선, 글자 크기와 굵기로 위계를 만든다. 그림자·그라데이션·장식 애니메이션은 쓰지 않는다.
- **은유**: 종이(paper) 위의 잉크(ink). 원문 근거만 형광펜(marker)으로 칠한다. 색은 상태(통과·실패·주의)와 링크에만 쓴다.
- **밀도**: 표준~조밀. 목록·표 중심이라 여백은 4px 단위로 촘촘하게, 구획 사이는 넉넉하게.

`search.py --design-system`이 추천한 값 중 다음은 일부러 따르지 않았다.

| 추천 | 채택하지 않은 이유 |
| --- | --- |
| 어두운 화면 기본, 녹색 강조색 | 문서를 오래 읽는 도구라 밝은 종이 화면이 기본. 녹색은 '통과' 상태색과 겹친다 |
| 제목에 JetBrains Mono | 한글 글리프가 없다. 고정폭은 ID·코드·DDL에만 쓴다 |
| IBM Plex Sans | 한글이 필요해 IBM Plex Sans KR을 쓴다 |
| FAQ/문서 랜딩 구성, 스크롤 등장 애니메이션 | 랜딩 페이지가 아니라 업무 화면이다 |

## 색

모든 색은 `var(--…)`로만 쓴다. 컴포넌트에 hex를 직접 쓰지 않는다. 밝은/어두운 화면 값은 `prefers-color-scheme`로 함께 바뀐다.

| 토큰 | 용도 | 대비 (밝음 / 어두움) |
| --- | --- | --- |
| `--paper` | 페이지 배경 | — |
| `--surface` | 패널·표·입력칸·hover 배경 | — |
| `--ink` | 본문 | 14.3 / 14.5 (paper) |
| `--ink-2` | 보조 글자, 메타 정보 | 6.7 / 7.9 (paper) |
| `--line` | 목록 구분선 (장식) | — |
| `--line-strong` | 구획 경계, 표 머리 | — |
| `--line-control` | 입력칸·버튼처럼 조작할 수 있는 것의 테두리 | 3.4 / 3.3 (surface, 비텍스트 3:1 이상) |
| `--accent` / `--accent-soft` | 링크, 선택된 항목, 포커스 링 | 7.0 / 5.8 (soft 위 글자) |
| `--pass` / `--fail` / `--warn` (+`-soft`) | 상태. 항상 글자나 기호를 같이 쓴다 | 5.3 이상 |
| `--marker` / `--marker-soft` | 원문 인용 형광펜. 다른 용도로 쓰지 않는다 | ink 13.6 |

규칙
- 상태는 색만으로 알리지 않는다: `통과`/`실패` 글자, `✓`/`✕` 기호를 같이 둔다.
- 원문에서 확인되지 않은 인용은 형광펜 대신 `--fail` 물결 밑줄.
- '가정' 표시는 `--warn` 계열.

## 글자

- 본문 `--font`: IBM Plex Sans KR → Apple SD Gothic Neo → Malgun Gothic
- 고정폭 `--mono`: JetBrains Mono — ID, 테이블·컬럼 이름, DDL, run_id
- 루트 크기는 `93.75%`(기본 15px). px로 고정하지 않아 브라우저 글자 크기 설정을 따른다.
- 한글 제목·항목명은 `word-break: keep-all`. 경로·ID처럼 긴 토큰은 `overflow-wrap: anywhere`.

| 토큰 | 크기 (기본 기준) | 용도 |
| --- | --- | --- |
| `--text-2xs` | 12px | 배지, ID, 인용 메타. 이보다 작게 쓰지 않는다 |
| `--text-xs` | 13px | 메타 줄, 표 머리, 보조 설명 |
| `--text-sm` | 14px | 버튼·입력칸·표 본문·조밀한 목록 |
| `--text-base` | 15px | 본문 |
| `--text-lg` | 18px | 엔티티 제목 |
| `--text-xl` | 24px | 페이지 제목, 큰 숫자 |
| `--text-2xl` | 39px | 완료 조건 판정 숫자 (화면당 하나) |

굵기: 본문 400, 라벨·항목명 500, 소제목 600, 제목·숫자 700. 숫자 열은 `font-variant-numeric: tabular-nums`.
줄 간격: 본문 1.6, 인용 1.75, 제목 1.35. 글 폭: `--measure`(72ch), 지적·예외처럼 표 형태는 `--measure-wide`(80ch).

## 간격·모양

- 간격은 4px 단위 `--space-1`(4) `--space-2`(8) `--space-3`(12) `--space-4`(16) `--space-5`(20) `--space-6`(24) `--space-7`(32) `--space-8`(48) `--space-9`(64). 2px 미세 간격만 `--space-px`.
- 같은 묶음 안 4–8, 묶음 사이 12–16, 구획 사이 24–32.
- 모서리: `--radius-sm`(4, 배지) `--radius`(6, 버튼·입력·목록 항목) `--radius-lg`(8, 패널). 원형은 `--radius-full`.
- 높이는 그림자 대신 선으로 구분한다. 그림자 토큰은 두지 않는다.
- 강조 막대: 선택·포커스된 항목은 왼쪽 3px `inset box-shadow`(`--bar`).

## 조작

- 클릭할 수 있는 것은 `cursor: pointer`와 hover 배경(`--surface`) 또는 테두리 변화가 있다.
- 조작 요소 최소 높이 `--control-h`(32px, WCAG 24px 이상). 터치 기기(`pointer: coarse`)에서는 44px.
- 포커스: `:focus-visible`에 `--accent` 2px 외곽선, 간격 2px. 지우지 않는다.
- 선택 상태는 `aria-current` / `aria-pressed`로 표시하고 CSS도 그 속성으로 칠한다.
- 비활성은 `disabled` 속성 + 불투명도 0.45 + `cursor: not-allowed`.

## 움직임

- 상태 변화(hover, 선택, 흐림)에만 짧게 쓴다. 등장·스크롤 애니메이션 없음.
- `--duration-fast`(120ms) 색·테두리, `--duration-base`(180ms) 불투명도. 곡선 `--ease`.
- 배경색·색·테두리색·불투명도만 바꾼다. 크기·위치는 애니메이션하지 않는다.
- `prefers-reduced-motion: reduce`이면 모두 끈다.

## 배치

- 2단: 왼쪽 사이드바 `--sidebar-w`(264px) + 본문. 900px 이하에서 1단.
- 탭 줄은 상단 고정(`--z-sticky`). 탭으로 이동한 항목은 `scroll-margin-top: var(--sticky-offset)`로 탭 줄에 가리지 않는다.
- 겹침 순서: `--z-sticky`(2) < `--z-skip`(10).
- 중단점: 900px(1단), 640px(목록 머리·필드 세로 쌓기). 375px에서 가로 스크롤이 없어야 한다 (표·DDL·ERD는 자기 상자 안에서만 스크롤).

## 상태 문구

- 불러오는 중: `…을 읽는 중…`, 실패: 원인 + 다음에 할 일(다시 시도 버튼, 명령어).
- 빈 목록: 왜 비었는지 한 줄 (`.empty`).

## 새 화면을 만들 때 확인

- [ ] hex·px 글자 크기를 직접 쓰지 않고 토큰을 썼다
- [ ] 상태를 색과 글자로 함께 표시했다
- [ ] 클릭 요소에 hover·focus-visible·cursor가 있다
- [ ] 375px 폭에서 페이지 전체 가로 스크롤이 없다
- [ ] 밝은/어두운 화면 둘 다 확인했다
